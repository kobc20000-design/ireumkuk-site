이용약관

청약콕 서비스 이용약관입니다.

본 약관은 청약콕(ireumkuk.co.kr/apt, 이하 "사이트")이 제공하는 서비스 이용에 관한 조건을 정합니다. 사이트를 이용함으로써 아래 내용에 동의한 것으로 간주됩니다.

1. 서비스 내용

사이트는 공공 API 데이터를 가공한 청약 정보 열람 및 계산기(가점 계산, 자금 계산 등)를 무료로 제공합니다. 별도의 회원가입 없이 이용할 수 있습니다.

2. 정보의 정확성

사이트가 제공하는 일정·분양가·경쟁률 등은 공공 API 및 모집공고문을 기초로 하되, API 갱신 주기·공고 정정 등의 사유로 실제와 다를 수 있습니다. 청약 신청 전 반드시 청약홈 및 해당 단지 모집공고문 원문을 확인하시기 바랍니다.

3. 계산기 결과의 성격

가점 계산기, 취득세·DSR·안전마진 계산기 등은 입력값을 기반으로 한 참고용 추정치이며, 법적·금융적 효력이 없습니다. 실제 세액·대출한도·당첨 여부는 관계기관의 최종 판단을 따릅니다.

4. 면책

사이트의 정보나 계산 결과를 신뢰하여 발생한 손해에 대해 운영자는 책임을 지지 않습니다. 사이트는 사전 고지 없이 서비스 내용을 변경하거나 중단할 수 있습니다.

5. 지식재산권

사이트가 자체적으로 가공·구성한 화면, 계산기 로직, 디자인의 저작권은 운영자에게 있습니다. 원본 공공데이터의 저작권은 각 제공 기관(한국부동산원, 국토교통부 등)에 있습니다.

6. 약관 변경

본 약관은 관련 법령 및 서비스 변경에 따라 개정될 수 있으며, 개정 시 본 페이지를 통해 공지합니다.
